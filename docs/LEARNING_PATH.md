# 4-week plan (about 6 to 8 hours per week)

**Week 1: Foundations.** Create OCI account and Always Free ADB. Learn the five OCI concepts in OCI_SETUP.md. Study: OCI Foundations and AI Foundations free training on Oracle MyLearn. Run scripts 00 to 02.

**Week 2: Vector search.** Run 03 and 04. Read Oracle's AI Vector Search User's Guide chapters on VECTOR type, distance metrics, indexes, and `DBMS_VECTOR`. Experiment with chunk sizes and exact vs approximate search; read the execution plans.

**Week 3: Generative AI and Select AI.** Set up IAM and the profiles in 05. Try NL2SQL on your own tables, record where it fails and why (missing comments, ambiguous names). Run 06 and fill in the Results table.

**Week 4: Consulting polish.** Do two extensions from the README. Write LESSONS_LEARNED.md, record the demo, rehearse the pitch and playbook questions, update your CV and LinkedIn with specific skills (AI Vector Search, Select AI, OCI Generative AI, RAG evaluation).

## Certifications worth considering
Check the current catalogue on Oracle MyLearn: OCI Foundations, OCI AI Foundations, and the Oracle AI Vector Search professional certification. Certifications support the project; they do not replace it.

## Skills gap list for the role (self-assess honestly)
OCI networking and IAM, Python for glue code, data pipelines (Data Integration, GoldenGate basics), Analytics Cloud, stakeholder communication, estimation and scoping.
